A clean, responsive weather dashboard built with **Vanilla JavaScript** and **Tailwind CSS v4**, providing real-time weather conditions, 3-day forecasts, and live local time for any city worldwide.

## ✨ Key Features

- **Live Weather Data:** Get up-to-date weather information for your current location or search for any city worldwide.
- **Live Local Clock:** Real-time clock and date synchronized to the searched city's timezone.
- **3-Day Forecast:** View upcoming weather conditions and daily temperature trends for the next 3 days.
- **Responsive UX:** Adaptive mobile-to-desktop layout with skeleton loading and interactive error modals.

## 🛠️ Tech Stack & Resources

- **Core:** HTML5, Tailwind CSS v4, Vanilla JavaScript (ES6+)
- **Build Tool:** Vite
- **API:** [WeatherAPI](https://www.weatherapi.com/)
- **Icons:** [Meteocons](https://meteocons.com/)
